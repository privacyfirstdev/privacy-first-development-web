Delete your Reddit chat messages.

A Chrome extension that deletes your own messages from Reddit Chat. It runs only in the tab you choose, sends nothing anywhere, and counts matches before it deletes anything.

What you keep

The extension collects nothing, so there is nothing to leak, sell or lose.

01

Your data stays in your browser

No accounts, no analytics, no servers. The extension makes no network requests of its own.

02

Only the tab you pick

It gets access to the active tab when you click its icon. It does not ask for access to all websites.

03

A count before any delete

Dry run is on by default. It counts matching messages and deletes nothing until you turn it off.

The popup

These are the only controls. Dry run stays on until you change it.

How a run works

Four steps, all inside one tab.

  1. Open reddit.com/chat in a tab.
  2. Click the extension icon and type your Reddit username, without u/.
  3. Press Check page, then run a dry run and read the counts.
  4. When you are ready, turn off dry run, tick the permanent-deletion box and press Start.
  • Confirmations for single messages are clicked for you. Anything that mentions a whole chat or conversation is left for you.
  • Closing the popup does not stop a run. Runs pause while the tab is hidden, and you can stop at any time.

Read this before you delete

Deleting is permanent. Do a dry run first.

  • It deletes chat messages only. It does not touch your posts or comments.
  • Reddit may flag automated activity, and your account could be affected. You use it at your own risk.
  • It has not been tested against live Reddit yet. Check the page and run a dry run before any real delete.
