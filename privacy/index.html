Privacy Policy: Delete My Chat Messages for Reddit

Effective date: October 17, 2026
Developer contact: support@privacyfirstdevelopment.com

Summary

The extension never collects your Reddit data. It has no accounts, no analytics, and no advertising. Everything it does to your chats happens inside the browser tab you choose, on your own machine.

If you buy a lifetime license, we run a small license server that stores your purchase email, your license key, and random IDs for the browsers you use it on. That is the only personal data we hold. We never sell or share it.

What the extension processes (locally only)

When you use the extension on a Reddit chat page, it processes the following inside your browser:

  • Your Reddit username, which you type into the popup. It is kept in memory for the duration of a run and is never saved to disk or sent anywhere.
  • Chat list and message content as it appears on the page. The extension reads this in order to find your messages and delete them. It does not copy or store message text.
  • A run log shown in the popup, which may include chat names and short message identifiers. It is held in memory and cleared when the tab reloads or the browser closes.

What the extension stores (locally only)

The extension uses chrome.storage.local on your device for:

  • A daily count of how many chats you have deleted messages from today, and the date. The free plan allows 3 such chats per day. The count holds no chat names, usernames, or message content, and resets each day.
  • A random install ID, created the first time you open checkout or activate a key. It identifies this browser to the license server and says nothing about you.
  • When you last opened checkout, so the popup knows to look for your purchase.
  • Your license key, if you have one.

All of this is removed when you uninstall the extension. Removing the license in the popup deletes the key.

Licenses and payments

The free plan deletes messages in up to 3 chats per day. A one-time lifetime license removes that limit. Test mode is never limited.

Payments are handled by Stripe through Stripe Managed Payments, with Link as the merchant of record. You pay on Stripe's checkout page, not inside the extension. Stripe's privacy policy covers the payment details you give them. We never see your card details.

When a purchase completes, Stripe tells our license server, which stores:

  • your email address (from checkout), to send you the license key and to handle support and refunds;
  • the license key and its status (active, or revoked after a refund or dispute);
  • Stripe's IDs for the checkout and payment, to match refunds to licenses;
  • the install IDs of the browsers the key is active on (up to 3).

The license server runs on Supabase. We send the key email through Resend. Neither may use the data for anything else.

The extension contacts the license server only:

  • when you click Buy, opening checkout with this browser's install ID so the purchase can unlock it;
  • for up to a day after you open checkout, while the purchase has not landed: when you open the popup, and every few seconds while it stays open, sending the install ID to see if it has arrived;
  • when you click Activate, sending the key and install ID;
  • about once a week while a license is active, sending the key and install ID to check it is still valid;
  • when you click Remove license, sending the key and install ID to free that slot.

These requests never include your Reddit username, chat names, or message content.

We keep purchase records for as long as the license is active, and afterwards as long as tax and accounting law requires. To have your email or activations deleted, write to the contact address below. Deleting them ends the license.

What the extension does not do

  • It does not send your Reddit data to the developer or to any third party.
  • It does not save your username, chat names, message content, or the run log. Its only storage is what is listed above.
  • It makes no network requests other than the license requests above. Its only effect on Reddit is the same actions you would take through Reddit's own interface (deleting messages, and optionally hiding chats).
  • It does not load or run remote code.

Diagnostics

The "Copy diagnostics" button builds a report on your clipboard when you click it. The report includes the extension version, browser user agent, page path shape, and element counts. It does not include usernames, chat names, room IDs, or message text. Nothing is sent anywhere; you decide whether to paste the report somewhere.

Permissions and why they are needed

  • activeTab: Grants access to the Reddit chat tab you have open, and only after you click the extension icon. It is what lets the extension act on that one tab.
  • scripting: Injects the extension's script into that tab so it can read the page and perform deletions.
  • storage: Keeps the daily free-plan count, install ID, and your license key on your device.

The extension does not request access to all websites.

Reddit's data handling

Reddit's own privacy policy and user agreement govern your data on Reddit. This policy does not change them. Deleting a message through this extension has the same effect as deleting it through Reddit.

Children

The extension is not directed at children under 13 and does not knowingly process their data.

Changes to this policy

If the extension's data handling changes, we will update this policy and the version history, and we will tell users through the store listing and in release notes before the change takes effect. Any change that adds data collection requires a new consent step in the extension.
