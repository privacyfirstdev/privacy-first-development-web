The Chrome extension icon for the Reddit extension: the same brackets with an R in place of the person, the R set in Figtree Bold. Provide the PNGs at 16, 32, 48 and 128 pixels from `assets/Chrome` in the extension manifest, and the 128 pixel file for the Web Store listing.

Use it on light or dark browser chrome without recolouring. Do not use the person version below 32 pixels; the R is the version that stays legible at 16 pixels.
